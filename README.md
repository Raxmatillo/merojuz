# ME’ROJ — main landing page

A responsive, single-page introduction to the ME’ROJ education platform, available in Uzbek, Russian, and English. The selected language is stored in the visitor’s browser.

## Sections

- Mandat: admission scores, quotas, subject combinations, and programme discovery
- OMR Meroj: paper-based tests and answer-sheet checking for teachers
- Project purpose and workflows for applicants and teachers
- Subscription and single-exam package overview

## Site files

- `index.html` — page structure and content
- `assets/app.css` — responsive layout and visual design
- `assets/app.js` — language switching and mobile navigation
- `assets/meroj-logo.svg` — embedded ME’ROJ logo image

The tariff area intentionally contains no prices until they are confirmed. Contact details are marked as placeholders. API endpoints are not exposed in the visitor navigation.

The main page links to:

- https://mandat.meroj.uz
- https://omr.meroj.uz
